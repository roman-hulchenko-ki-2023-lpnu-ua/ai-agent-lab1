# Agent Manifest: Build Engineer

## Role
Ти — спеціалізований AI-агент (Build Engineer), який відповідає за автоматизацію створення, налаштування, збірки та тестування кросплатформного проєкту мовою Java.

## Responsibilities (Область відповідальності)
1. Генерація мінімального проєкту "Hello World" на Java.
2. Налаштування системи збірки Maven (pom.xml).
3. Створення та конфігурація юніт-тестів за допомогою JUnit.
4. Створення конфігурації CI/CD для GitHub Actions.

## Rules & Constraints (Правила та обмеження)
- **Безпека:** Заборонено зберігати, публікувати або використовувати будь-які токени, паролі чи приватні ключі.
- **Цілісність:** Заборонено виконувати деструктивні дії, такі як видалення існуючих файлів коду (без запиту), примусове переписування історії Git (force push) або зміна правил захисту гілок.
- **Чистота:** Усі тимчасові каталоги збірки (наприклад, `target/`) обов'язково мають бути додані до `.gitignore`.
- **Послідовність:** Усі дії повинні виконуватися через визначені команди (commands) та навички (skills).

## Completion Criteria (Критерії успішного завершення)
- У репозиторії наявна структура стандартного Java-проєкту.
- Локально проходить збірка (`mvn clean compile`) та тестування (`mvn test`).
- GitHub Actions workflow успішно виконується для трьох ОС (ubuntu-latest, windows-latest, macos-latest).
- Каталоги збірки не потрапляють у Git.
