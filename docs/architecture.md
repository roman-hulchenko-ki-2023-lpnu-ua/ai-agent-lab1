# Архітектура AI-агента

## Проблема
Автоматизація створення, налаштування та тестування кросплатформного Java-проєкту (Maven + JUnit).

## Скіли (Skills)
- `project-scaffold`: створює базову структуру Java-проєкту.
- `build-and-test`: налаштовує Maven (pom.xml) та створює базові тести JUnit.
- `github-actions`: генерує конфігурацію CI для Windows, Linux та macOS.

## Команди (Commands)
- `git-init`: ініціалізація Git та створення .gitignore.
- `create-project`: запуск скіла створення проєкту.
- `create-build`: запуск скіла налаштування Maven та тестів.
- `create-actions`: запуск скіла створення GitHub Actions workflow.
- `check`: перевірка коректності виконання всіх кроків.
- `init`: оркестратор, що послідовно викликає всі команди.

## Обробка помилок
Оркестратор зупиняє виконання процесу, якщо будь-яка з команд повертає помилку або не проходить фінальну перевірку.
